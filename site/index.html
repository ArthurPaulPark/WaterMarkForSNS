보이지 않는 워터마크로
내 사진 지키기

SNS에 올린 사진이 어디로 퍼졌는지 추적하고, 내가 원작자임을 증명합니다. 육안으로는 아무 차이가 없고, 사진은 내 컴퓨터를 벗어나지 않습니다.

GitHub에서 받기 설치 방법 못 하는 것

macOS · Python 3 · 오픈소스(MIT) · 설치 후 인터넷 불필요

무엇을 하나

사진에 세 겹의 흔적을 남깁니다.

작성자 태그

내 공개키를 가리키는 48비트 표식. 재압축·크롭·노이즈 제거를 견디고, 남이 그 위에 다시 워터마크를 심어도 살아남습니다.

문장 심기

원하는 문장을 사진 안에 넣습니다. 한글 29~111자. 정확히 복원됐을 때만 보여줍니다.

서명 (사이드카)

Ed25519 서명으로 원작자를 증명합니다. 분쟁이 생겼을 때 부인할 수 없는 근거가 됩니다.

실제로 견디는가

인스타그램 1080px 기준 실측. 48비트 중 몇 비트가 살아남는지.

공격결과공격당한 사진 화질
업로드 재압축48/48 검출39dB
스크린샷 캡처48/48 검출38dB
저장 후 50% 축소48/48 검출39dB
정중앙 40%만 남김 (크롭)48/48 검출16dB
노이즈 제거 (제거 시도)47/48 검출37dB
밝기·대비 조작48/48 검출18dB
남이 덮어쓰기41~44/48 검출—
크롭 + 밝기·대비 동시소실13dB
AI 재생성 (img2img)소실—

오른쪽 dB는 공격당한 사진 자체의 화질입니다. 워터마크를 지울 만큼 센 공격은 사진도 같이 망가집니다. 워터마크를 넣었을 때의 화질 손실은 PSNR 40dB로 육안 식별이 불가능합니다.

사진은 어디로도 가지 않습니다

서버가 없습니다. 내 컴퓨터 안에서만 돕니다.

  • 외부 연결 0건 — 사진 처리 내내 소켓을 감시해 확인했습니다.
  • 127.0.0.1 전용 — 같은 네트워크의 다른 기기에서도 접근할 수 없습니다.
  • 디스크에도 안 남습니다 — 사진은 메모리에서만 처리됩니다.
  • 안 쓰면 꺼집니다 — 10분간 사용이 없으면 스스로 종료합니다.
  • 개인키는 브라우저로도 나가지 않습니다 — 서명은 내 컴퓨터에서만 이뤄집니다.

웹사이트에서 바로 쓸 수는 없나요?

그렇게 만들면 사진을 서버로 보내야 합니다. 이 도구의 존재 이유가 사라지므로 일부러 내려받아 쓰는 방식으로 만들었습니다. 이 페이지는 소개용입니다.

설치

macOS 기준. 처음 한 번만 1~2분 걸립니다.

  1. GitHub에서 코드를 내려받습니다 초록색 Code 버튼 → Download ZIP → 압축 풀기
  2. 폴더 안의 실행.command 를 더블클릭합니다 필요한 부품을 알아서 내려받고 브라우저가 자동으로 열립니다
  3. 첫 화면에서 "내 도장"을 한 번 만듭니다 암호를 걸지 여부만 고르면 됩니다. 만든 개인키는 꼭 백업하세요
  4. 사진을 끌어다 놓고 [보호하기] 내려받은 이미지를 SNS에 올리고, 사이드카 파일은 따로 보관합니다

터미널을 쓴다면:

git clone https://github.com/ArthurPaulPark/WaterMarkForSNS.git
cd WaterMarkForSNS
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python server.py     # → http://127.0.0.1:8765

못 하는 것

이건 도용 방지 도구가 아니라 도용 추적 도구입니다.

  • 훔쳐가는 것을 막지 못합니다. 사후에 "내 것"임을 보이는 도구입니다.
  • AI 학습을 막지 못합니다. 국제 표준(IPTC/PLUS)의 학습 거부 표시를 넣지만 강제력이 없고, SNS 업로드 때 지워집니다.
  • AI 재생성(img2img)을 거치면 사라집니다. 현재 모든 비가시 워터마크의 공통 한계입니다.
  • 크롭과 색보정이 겹치면 놓칠 수 있습니다.
  • 표적 공격은 막지 못합니다. 내 공개키를 알고 코드를 고치는 상대는 지울 수 있습니다.
  • 먼저 만들었다는 것은 증명하지 못합니다. 서명의 시각은 자기 신고입니다.

과장하지 않는 것이 이 프로젝트의 원칙입니다. 모든 수치는 실측이고, 실패한 시도까지 문서에 남겨두었습니다.
